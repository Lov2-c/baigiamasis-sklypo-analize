# Baigiamasis darbas

Automatinė sklypo statybos galimybių analizės sistema naudojant GIS ir mašininį mokymąsi.

## Projekto tikslas
Sukurti sistemą, kuri pagal vartotojo pasirinktą sklypą:
- nustato bendrojo plano zoną,
- analizuoja teritorinius apribojimus,
- suformuoja požymius modeliui,
- prognozuoja statybos palankumą,
- pateikia rezultatą vartotojo sąsajoje.

## Tikslinės klasės
- palanku
- ribota
- nepalanku

## Pagrindinės technologijos
- Python
- QGIS
- GeoPandas
- SQLAlchemy
- Flask
- scikit-learn
- neuroninis tinklas
